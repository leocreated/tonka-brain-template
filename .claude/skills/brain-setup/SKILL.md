# Brain setup

This skill is a thin entry point. The instructions live in one shared guide used by every agent:

1. From the repository root, read `system/setup/GUIDE.md` completely before doing anything else.
2. Follow it step by step. It covers first-time setup, resuming, revising, and joining from a second device.

Do not improvise a different flow, and do not write personal answers into tracked files before the guide's privacy gate passes.
