# context

Stable facts about you that agents should read before working with you: profile, preferences, priorities and memory policy. Setup writes the first versions here after you review them.

- One topic per file: `profile.md`, `preferences.md`, `priorities.md`, `memory-policy.md`.
- `setup.md` marks the brain as set up. Other devices detect it and join instead of repeating the interview.
- Edit these files directly whenever something changes. Update the `date:` field when you do.
- Never store passwords, API keys, recovery codes or ID numbers here or anywhere else in the brain.

New file: `node system/bin/brain.mjs new context "Title"`. Format: system/docs/record-format.md.
