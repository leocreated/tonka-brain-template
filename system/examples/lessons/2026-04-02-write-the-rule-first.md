# Write the rule before the story (fictional example)

Fictional example lesson.

## Rule

Start every lesson with the instruction to follow next time. The story comes second.

## What happened

Three old lessons were long stories; agents quoted the story and missed the point.

## How to apply

When closing a session, ask "what would I tell myself next time?" and write that line first.
