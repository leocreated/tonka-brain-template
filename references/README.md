# references

Pointers to things that live elsewhere: documentation, dashboards, accounts you use (by name only), reading lists, and how to find things.

- Subfolders are fine (`references/tools/`, `references/reading/`); the index walks them recursively.
- Store links and descriptions, never credentials. Name the password manager entry instead of copying a secret.

New file: `node system/bin/brain.mjs new reference "Title"`. Format: system/docs/record-format.md.
