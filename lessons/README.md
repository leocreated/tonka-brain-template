# lessons

One dated lesson per file: something you learned the hard way and want agents (and future you) to apply.

- File name: `YYYY-MM-DD-short-slug.md`.
- State the lesson as a rule you can act on, then the evidence that taught it.
- Archive lessons that stop being true instead of deleting them.

New file: `node system/bin/brain.mjs new lesson "The lesson in one line"`. Format: system/docs/record-format.md.
