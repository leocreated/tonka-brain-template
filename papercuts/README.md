# papercuts

One dated papercut per file: a small, recurring friction worth fixing later (a confusing command, a flaky step, a missing shortcut).

- File name: `YYYY-MM-DD-short-slug.md`, `status: open` until fixed.
- When fixed, set `status: resolved`, note the fix, and archive it.
- Do not record every minor annoyance; record the ones that repeat or cost real time.

New file: `node system/bin/brain.mjs new papercut "What keeps going wrong"`. Format: system/docs/record-format.md.
