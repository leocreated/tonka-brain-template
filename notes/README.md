# notes

Dated working notes that do not fit elsewhere yet: meeting notes, research scraps, session summaries.

- File name: `YYYY-MM-DD-short-slug.md`.
- When a note produces a decision, lesson or papercut, write that as its own record and link back.
- Archive notes that are no longer useful.

New file: `node system/bin/brain.mjs new note "Topic"`. Format: system/docs/record-format.md.
