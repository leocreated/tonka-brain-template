# decisions

One dated decision per file: what you decided, why, what you rejected, and when to revisit.

- File name: `YYYY-MM-DD-short-slug.md`. One decision per record keeps search and archiving simple.
- `status: active` while it holds. When a later decision replaces it, set `superseded_by` and archive the old one.

New file: `node system/bin/brain.mjs new decision "What was decided"`. Format: system/docs/record-format.md.
