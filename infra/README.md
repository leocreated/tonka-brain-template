# infra

How your working environment is set up: devices you use (by a label you choose), agent and tool installation notes, backup routines, and recovery steps.

- Subfolders are fine; the index walks them recursively.
- No credentials, recovery codes or private keys. Describe where a secret lives, not the secret.
- Device labels are your choice. Nothing in TONKA depends on a particular device name.

New file: `node system/bin/brain.mjs new infra "Title"`. Format: system/docs/record-format.md.
