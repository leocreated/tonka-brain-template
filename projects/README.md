# projects

One file (or one folder with an `index`-style file plus notes) per active project: goal, status, key links, where the code lives, and open questions.

- Product code, its tests and its development rules stay in the product's own repository. A project record here points to that repository instead of copying its rules.
- Use `status: active`, `paused` or `done`. When a project is finished, archive it (see archives/README.md).

New file: `node system/bin/brain.mjs new project "Project name"`. Format: system/docs/record-format.md.
